# Serotonergic PCI estimators and convergence analysis

This note documents the two perturbational-complexity estimators used for the
serotonergic simulations. Both estimators operate on trials that have first
been cut around their own stimulation time and then aligned to a common
stimulation-onset sample. Neither estimator averages independently calculated
single-trial PCI values.

## Statistical source threshold for Lempel-Ziv PCI

The production default is `pre_post_swap`. It implements the explicit
source-level permutation procedure described by Pantazis et al. (2005) and
adopted by Casali et al. (2010):

1. Each aligned trial contains an equal-duration prestimulus block and
   poststimulus block.
2. A permutation is generated by independently flipping a virtual coin for
   every trial. On heads, that trial's complete pre and post blocks are
   exchanged. One decision is used for every source and time sample in the
   trial, so the trial's spatial and temporal structure is preserved.
3. The baseline mean and standard deviation are recalculated from the
   permuted prestimulus blocks.
4. The permuted trials are averaged and converted to a baseline-normalized
   statistic.
5. At each response latency, the largest absolute statistic across all
   sources is retained. This controls the chance of falsely calling any source
   active at that latency.
6. Steps 2--5 are repeated 1,000 times. Corrected Monte Carlo p-values are
   calculated with the conservative plus-one rule, and a source-time cell is
   active when its corrected p-value is at most 0.05. This is the configured
   threshold for the serotonergic simulation analyses; empirical reproduction
   utilities retain the published 0.01 convention.

The result is one binary source-by-time matrix for the trial-averaged evoked
response. Lempel-Ziv complexity is calculated on the 8--300 ms portion and
normalized by the binary matrix's source entropy. As in empirical PCI work,
PCI is set to zero when source entropy is at or below 0.08, because a
vanishingly sparse matrix gives an unstable normalization.

On the saved simulations' 7.8125-ms sampling grid, requested time boundaries
usually do not land exactly on samples. The analysis therefore records both
the requested window and the samples actually included; for example, an
8-ms lower bound advances to the first sample at or after 8 ms rather than
pretending that an 8-ms sample exists.

The older `temporal_shuffle` and `trial_bootstrap` nulls remain available as
explicit sensitivity analyses. They are not production defaults.

Important assumption: under the no-response hypothesis, equal-duration pre
and post blocks must be exchangeable. Strong drift or a systematic change
unrelated to stimulation can violate that assumption.

## PCI-ST

PCI-ST is a different estimator, not another threshold for Lempel-Ziv PCI.
The implementation follows Comolatti et al. (2019) and the authors' reference
Python equations.

1. The low-level PCI-ST function accepts one already preprocessed,
   trial-averaged response. The model-cache convenience wrapper baseline-centers
   each aligned trial and then averages it; centering the average over the same
   baseline gives the same result.
2. Singular-value decomposition finds a compact set of spatial response
   components.
3. Components that explain the requested response variance are retained, and
   components with response-to-baseline signal-to-noise ratio at or below 1.1
   are discarded.
4. For each retained component, the algorithm compares every time point with
   every other time point and asks whether the pair represents the same
   recurrent state at a candidate distance threshold.
5. It counts changes between recurrent and non-recurrent states in the
   response and subtracts 1.2 times the corresponding baseline transition
   rate.
6. The threshold giving the largest excess response transition rate is
   selected for each component. A nonpositive winning contribution is clipped
   to zero, and the remaining component contributions are summed.

PCI-ST does not use the Casali permutation significance matrix, Lempel-Ziv
compression, or the 0.08 source-entropy rule. It is nonnegative but is **not
bounded between zero and one**. Therefore, its numbers cannot be compared
with the original PCI scale or with the clinical PCI cutoff of 0.31.

The public APIs are:

```python
from tvbtoolkit.complexity import pci_st, pci_st_from_trials
```

`pci_st` expects `(channels, time)` data. `pci_st_from_trials` expects the
explicit shape `(trials, channels, time)` and stimulation-locked relative
times in milliseconds. The serotonergic loader returns each epoch as
`(time, region)`, so the convergence analysis transposes each epoch before
stacking it.

The implementation defaults match the reference algorithm
(`k=1.2`, `min_snr=1.1`, `max_var_percent=99`, `n_steps=100`, no time-delay
embedding). The reference TMS/EEG baseline is -400 to -50 ms; the saved
serotonergic epochs begin at -300 ms, so analyses of those cached simulations
must explicitly use the available -300 to -50 ms baseline and record that
adaptation. PCI-ST rejects irregular sampling and requests extending materially
outside the available epoch, and its diagnostics record the sampling interval
and effective first/last samples.

These inputs are AAL90 regional firing rates, not empirical sensor EEG or a
source reconstruction. Consequently, model PCI-ST values are useful for
within-model dose and convergence comparisons but are not numerically
comparable to empirical PCI-ST values or clinical cutoffs.

## Trial-count convergence

The convergence analysis reads the existing corrected NPZ simulation cache.
It never reruns or modifies a simulation.

- It selects subjects within each cohort without looking at their PCI values.
- For each repeat, trial seeds are randomly ordered once using a recorded
  deterministic seed.
- The first 20 trials are contained in the first 40, which are contained in
  the first 60, then 80, then all 100.
- The same subject-specific trial subsets are used at every receptor
  occupancy, preventing a dose comparison from being confounded by different
  random trials.
- The 100-trial value is calculated once and used as that subject's numerical
  reference.
- Both Lempel-Ziv PCI and PCI-ST are recomputed.
- Error versus 100 trials and dose-effect direction are summarized across
  repeats.

The default pilot selects one subject per cohort (five subjects total), uses
five nested resampling repeats, and targets the official PCI-ST response window
of 0--300 ms. If a requested boundary falls just beyond the last cached sample,
the analysis clips it to the cache's half-open sample edge and records the
target, available, and effective windows in every estimate.

On the HPC, submit the cache-only analysis with:

```bash
sbatch hpc/submit_serotonergic_pci_trial_convergence.sh
```

Because repeated nested subsets overlap, their spread is a numerical
stability assessment, not a conventional confidence interval and not an
inferential p-value.

The source-level randomization implemented here follows the explicit
Pantazis/Casali 2010 description. The historical Casali 2013 MATLAB
supplementary implementation was not available for byte-level comparison, so
the code does not claim software-identical reproduction of that executable.
